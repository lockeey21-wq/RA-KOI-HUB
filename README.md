# Grandad Ray & Adam's Koi Hub

A multi-page koi-keeping website designed for GitHub Pages.

## Pages
- Home
- Our Story
- Koi
- Ponds & Filtration
- Water Quality
- Pond Plants
- Koi Health
- Pond Volume Calculator

## Adding photos
Place your own photos in `assets/` and name the main background images:
- `koi-hero.jpg`
- `koi-pattern.jpg`

The Grandad Ray photo can replace the placeholder in `our-story.html` when you are ready.
